# D405 多视角点云手眼细化

用户自行固定物体、连接 D405/CAN 并启动重力补偿；采集程序只通过 SocketCAN 接收反馈，不发送机械臂控制命令。
它与原手眼采样窗口独占同一相机；运行前请自行关闭旧窗口。

```bash
cd /home/a/Nero-7
bash scripts/run_icp_handeye.sh collect --can can1
```

默认 D405 序列号为 262622274345。窗口同时显示深度着色图和 RGB 参考图。
拖动左臂从多个方向观察固定物体，保持清晰、相邻视角保留重叠；停稳后在窗口按 `s`。
在弹出的深度图上框选物体，按空格或回车确认，Esc 取消；每次都框选，尽量减少桌面/背景。
每组需要连续静止反馈；程序不进行硬件时间同步，检查主机接收时间和静止窗口。
采集建议 8–12 组不同角度，按 `q` 结束。数据目录和可直接复制的解算命令会在终端打印。

结束后，把终端打印的实际目录复制到命令中：

```bash
bash scripts/run_icp_handeye.sh solve /home/a/Nero-7/calibration_data/icp_你的目录
```

解算采用 RegHEC 的 AA-ICP，初值来自采集开始时快照的 13 组 Park 候选。
每组 `viewNd.pcd` 为 D405 **彩色光学系**的 XYZ（米），深度点经过 SDK 的 depth→color 外参变换；
第 N 行 `RobotPoses.dat` 为对应 `T_base_gripper`，ZYX 旋转角以弧度，平移以毫米。
同时保存原始 16 位深度、RGB 图像、选框、关节角、时间配对和相机参数。
输出 `icp_candidate.json`、`handeye_matrix.csv`、`registered_merged.pcd`、`solve.log`；不会覆盖现有标定。
终端显示的配准误差是同批点云训练拟合，不是实物精度；需保留新视角和物理测量作独立验证。

默认深度保留 0.07–0.60 m，可用 `--z-min`、`--z-max` 修改。深度彩色图为选框提示，黑色无效点不会保存。
采样时应避免反光、遮挡和物体移动。ROI 是矩形，背景混入会影响解算，需要尽量贴近物体轮廓。
注意不同视角必须看到足够共同表面，完全不重叠的点云无法可靠配准。

目前只完成 SDK 坐标约定检查、二进制 PCD/机器人位姿保存检查、上游9视角示例和自造7视角数据的离线求解验证；
本轮没有 D405 或 CAN，未验证实际相机双流带宽、深度质量、图形框选或现场标定精度。
如软件环境重建，可运行 `bash scripts/build_icp_handeye.sh`：依赖下载/解压在项目内，不安装到系统。
