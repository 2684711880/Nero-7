# Joy-Con 验证证据（2026-10-30）

这些文件是本台NERO硬件与对应软件版本的历史结果，不是待执行轨迹。

| 文件 | 证据范围 |
| --- | --- |
| `imu_20deg_report.json` / `imu_20deg_analysis.json` / `imu_20deg_analysis.png` | 修改前的90秒双手柄只读采样：旧20°映射限幅、原始角速度与积分结果。没有机械臂运动命令，不能把积分角度当作真实姿态基准。 |
| `limit90_replay.json` | 对同一份历史输入离线比较20°与90°限幅，不是新真机运行。 |
| `euler_boundary.json` / `euler_boundary.csv` | 工程准备姿态附近的合成四元数轨迹经过实际官方ROS转换，复现0.1°空间步长对应180°欧拉分量表示切换；不证明固件IK支路发生切换。 |
| `return_feedback.json` | 一次真实低速归位后的完整七轴被动反馈复核；仅关节目标到位验证，不是碰撞或姿态精度验收。 |
| `joint_limit_check.json` | 仅被动反馈的官方精确限位核对，说明J6约−41.96°仍位于官方范围内；此检查没有发出运动命令。 |

原始7 MB陀螺仪CSV、完整控制台日志、校准备份与生成文件留在本机。回归测试入口为 `bash scripts/test_joycon.sh`，其中真实手柄和真机测试不会自动运行。当前夹爪二态修复及精确限位修复的结论来自隔离模拟/单元测试与只读真机核对；没有宣称所有新修改都完成了真机动作验收。
