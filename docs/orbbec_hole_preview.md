# 中间 Gemini 336L：孔检测预览

这一步只读取相机，不连接 CAN，也不发送机械臂指令。使用原生深度图及其内参、畸变参数；检测板面上的圆形孔，彩色图只用于观察，两个窗口没有做像素对齐。

```bash
cd /home/a/Nero-7
bash scripts/preview_orbbec_hole.sh
```

绿色椭圆表示检测到一个候选孔；数字依次为孔径和孔中心在**深度光学坐标系**的 X、Y、Z，单位毫米。红字表示当前未检测到或存在多个候选。黑色表示无深度；无深度可能来自反光、遮挡或测量失败，不能仅凭黑色区域认定真实有孔。算法还要求有效板面和孔边，但实际准确性需要现场验证。

按 `s` 保存彩色图、原始深度、检测画面和深度比例/内参/检测结果到 `captures/orbbec_hole_时间/`；在预览窗口按 `q` 或 Esc 退出；也可在启动终端按 Ctrl+C。原始深度图的整数乘 metadata 中 `depth_scale_mm` 才是毫米。默认孔径范围 42.5–120 mm，可以按实际板孔调整，例如：

```bash
bash scripts/preview_orbbec_hole.sh --min-diameter-mm 70 --max-diameter-mm 110
```

多台奥比中光设备时用 `--serial 序列号` 指定。若相机未枚举，先检查线缆、供电和 `lsusb`；若被其他程序占用，先关闭其他相机程序。SDK Python 路径可以通过 `ORBBEC_HOLE_PYTHON` 覆盖。

后续右臂戳洞前，还需要固定相机到右臂基座的经验证标定、夹持工具 TCP 和误差评估；当前检测结果不能直接作为机械臂运动目标。检测器针对近圆形孔，板面视角、距离、孔径、深度噪声与缺失都会影响结果。
