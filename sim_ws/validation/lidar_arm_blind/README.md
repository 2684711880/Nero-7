# 机械臂直接回波的近距过滤范围

计算范围：当前默认 AIR/双 NERO 装配，包含两侧机械臂、夹爪和腕部相机的 28 个碰撞链接；按碰撞网格顶点和 URDF 运动链计算。与扫描视场无关的几何保守上界，因而可能明显大于真正能被雷达照到的最远机械臂表面。

| 默认安装 | xyz / m，AIR base_link 下 | 整臂几何距离上界 | 加至少 5 cm 余量并按 5 cm 取整 |
|---|---|---:|---:|
| chassis_up | (0.20, 0, 0.31) | 1.55272 m | `lio_blind:=1.65` |
| chest_down | (0.16, 0, 0.76) | 1.22243 m | `lio_blind:=1.30` |

计算用肩部固定旋转中心 A。对各碰撞表面顶点 P，以三角不等式界定：

`distance(sensor, P) ≤ distance(sensor, A) + sum(后续关节原点平移长度) + sum(移动关节最大行程) + max(局部碰撞顶点到链接原点的距离)`。

旋转不改变向量长度。分别计算每个链接并取最大值，因此覆盖所建模关节旋转范围，包含不可能碰撞自由到达的姿态，属于有意保守的包络。另用 100 个关节限位内随机姿态和网格顶点子集做实现一致性抽查，没有超过该上界；这些随机姿态没有在仿真或实机执行，也不代表合法作业轨迹。结论不包含手持物、线束、模型缺失部分和实机安装误差。

这只能剔除直接落在机械臂上的点。机械臂仍可能挡住远处货架，也可能通过动力学振动影响传感器；增大近距阈值不能补回被挡住的场景，不能称为完全不受机械臂影响。

代价：阈值内的环境点也会丢失。按默认高度、平地和名义视场估算，底盘正装的最近地面交点本来就约 2.52 m；胸前倒装本来约 0.59 m，但阈值 1.30 m 会把地面内圈扩大到约 `sqrt(1.30²−0.76²)=1.05 m`。均为相对雷达地面投影点的水平距离，未计实际车体遮挡和地面倾斜。

重新计算：加载 `/home/a/Nero-7/sim_ws/install/setup.zsh` 后，在工程根目录执行 `python3 scripts/calculate_lidar_arm_blind.py`。安装坐标读取已安装的 `mid360_mounts.yaml`；命令行覆盖安装坐标时须同步配置后重新计算，不能直接沿用本表。`report.json` 保存逐链接上界，`model.urdf` 为计算时模型快照。

实时原始数据：RViz 勾选 `Raw MID360 (before LIO filter)`，取消 `LIO map`，`Decay Time=0` 显示最新帧。显示话题 `/mid360/points`；原始 Livox 消息为 `/mid360/lidar`，含逐点坐标和相对时间。只观察传感器坐标时可把 RViz Fixed Frame 改为 `mid360_link`。
